# Retro

Small, frequent, evidence-based. One improvement per retro beats ten ideas.

## measure
skill: tasks
expect: metrics read and the bottleneck named
`tasks metrics`. Where does time pool — doing (tasks too big), review
(verification debt), blocked (external waits)? Name ONE bottleneck with the
numbers that show it.

## improve
skill: memory
expect: one concrete improvement stored durably
Decide one change: a WIP limit tweak (`tasks wip`), a splitting rule, a
criteria template, an escalation habit. Store it:
`memory remember 'kanban retro: <change and why>' --tier semantic`. If it
changes board policy, also update skills/Kanban/SKILL.md.
